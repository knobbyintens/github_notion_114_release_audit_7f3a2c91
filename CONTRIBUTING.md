# Contributing

1. Work on your own contributor branch, never on `main`.
2. Deliver packages in batches. Use a commit message of the form
   `Work on N tasks: package-a, package-b`.
3. A released package directory must contain `docs/task.md`, `evaluation/main.py` and
   `preprocess/main.py`. Optional support files (`docs/user_system_prompt.md`,
   `initial_workspace/`, `groundtruth_workspace/`) may be provided when relevant.
